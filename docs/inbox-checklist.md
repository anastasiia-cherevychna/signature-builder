# Inbox checklist

Run this whenever `src/template/` changes, and once per new client. Use the live link (images must be public).

Make one signature with **everything** filled in (photo, logo, website, email, phone, LinkedIn, CTA, quote) and one with **only** name and title. For each email app: install the signature, send an email to a Gmail address and to an Outlook address, and check the received email.

| Gmail (iPhone / Android app, receiving) | | | | | |
| Outlook on the web | | | | | |
| New Outlook (Windows / Mac) | | | | | |
| Classic Outlook for Windows | | | | Square corners are expected | |
| Apple Mail (Mac) | | | | | |
| iPhone Mail (receiving) | | | | | |

Known and expected:
- Classic Outlook for Windows shows the CTA button with square corners.
- Some apps hide images until the recipient clicks "show images".
- Dark mode varies by app; a logo on a white background shows as a white box in dark mode. That's why the form asks for JPG on white.
