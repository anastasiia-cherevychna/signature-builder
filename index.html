Each recipient’s email app applies its own dark mode, so check your logo works on both.

How to install:
  1. Click Copy signature above.
  2. In Gmail on a computer, click the cog (top right), then See all settings.
  3. Scroll to Signature, click Create new, give it a name, then paste into the box (Ctrl/⌘ + V).
  4. Under Signature defaults, choose it for new emails and for replies.
  5. Scroll to the bottom and click Save changes.

Outlook on the web, and the new Outlook for Windows and Mac:

  1. Click Copy signature above.
  2. Open Settings (the cog), then Account › Signatures.
  3. Click New signature, give it a name, and paste into the box (Ctrl/⌘ + V).
  4. Choose it as the default for new messages and for replies, then click Save.

Classic Outlook for Windows:

  1. Click Copy signature above.
  2. Go to File › Options › Mail › Signatures, then click New and name it.
  3. Paste into the edit box, set it as the default for new messages and replies, and click OK.
  4. If the layout looks wrong after pasting, click Download HTML, open the file in your browser, select all (Ctrl + A), copy, and paste again.
  1. Click Download HTML above and open the file in Safari.
  2. Select everything (⌘ + A) and copy it (⌘ + C).
  3. In Mail, go to Mail › Settings › Signatures, pick your account, and click +.
  4. Untick Always match my default message font, then click into the signature box and paste (⌘ + V).
  5. Close Settings. If images don’t show inside Settings, send yourself a test email; they usually appear there.

After saving, send yourself an email to check everything shows correctly.
